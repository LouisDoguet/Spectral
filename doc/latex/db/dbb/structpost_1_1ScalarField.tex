\doxysubsection{Detailed Description}
Descriptor for a scalar point-\/data field written to VTU. 

{\ttfamily fill} is called once per element. It writes {\ttfamily n\+\_\+plot} values into {\ttfamily out}. Parameters mirror the element\textquotesingle{}s basis so lambdas can do Legendre interpolation when needed.
