\doxysubsection{Detailed Description}
Train a policy network to choose the hybrid-\/\+DGSEM blending factor alpha by one-\/step-\/lookahead reward maximization (RL / policy iteration). 

This is the data-\/generation + training pipeline described in RL\+\_\+\+ALPHA\+\_\+\+APPROACH.\+md, specialized to what the hybrid-\/\+DGSEM residual actually exposes. Key structural fact exploited here\+: in compute\+Hybrid\+Residual() the inter-\/element interface fluxes are ALWAYS the entropy-\/stable flux, so the residual of element e depends only on alpha\mbox{[}e\mbox{]}. Therefore a single residual evaluation at a candidate alpha value gives, for every element simultaneously, the one-\/step update it would experience at that alpha.

Pipeline\+:
\begin{DoxyEnumerate}
\item Run a baseline hybrid-\/\+DGSEM trajectory (Persson-\/\+Peraire alpha) on the Sod shock tube.
\item At sampled timesteps, for each candidate alpha in \{0.\+0, 0.\+1, ..., 1.\+0\}\+:
\begin{DoxyItemize}
\item evaluate the hybrid residual,
\item form the forward-\/\+Euler update U\textquotesingle{} = U -\/ dt\texorpdfstring{$\ast$}{*}R for every element,
\item score each element with a reward\+: R = -\/(new-\/extrema overshoot) -\/ lambda \texorpdfstring{$\ast$}{*} alpha (with a hard penalty for states that lose positivity of rho or p). The argmax-\/over-\/alpha is the optimal blending label for that element.
\end{DoxyItemize}
\item Train a per-\/element network (standardized density profile -\/\texorpdfstring{$>$}{>} alpha).
\item Save the model (.nn).
\end{DoxyEnumerate}

Rationale for the reward\+:
\begin{DoxyItemize}
\item Smooth regions\+: every candidate keeps the solution monotone (overshoot=0), so the lambda\texorpdfstring{$\ast$}{*}alpha cost selects alpha=0 -\/\texorpdfstring{$>$}{>} full high-\/order accuracy.
\item Shock regions\+: low alpha creates new extrema (Gibbs), large overshoot; the smallest alpha that suppresses the oscillation wins -\/\texorpdfstring{$>$}{>} just enough first-\/order dissipation. This is exactly the desired blending policy. 
\end{DoxyItemize}
