\doxysubsection{Detailed Description}
Diffusion driven by a trained neural network. 

The network predicts optimal alpha values for the hybrid DGSEM solver. Takes nodal density/energy values and outputs alpha \mbox{[}0,1\mbox{]} for blending between high-\/order and low-\/order (FV) flux computations.

For hybrid DGSEM\+: R = alpha \texorpdfstring{$\ast$}{*} R\+\_\+\+FV + (1-\/alpha) \texorpdfstring{$\ast$}{*} R\+\_\+\+DG

Input\+: Concatenated nodal values \mbox{[}rho\+\_\+elem0, ..., rho\+\_\+elemN\mbox{]} Output\+: Per-\/element alpha values \mbox{[}alpha\+\_\+elem0, ..., alpha\+\_\+elemN\mbox{]}
