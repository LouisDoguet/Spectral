\doxysubsection{Detailed Description}
Trained policy network that predicts the hybrid-\/\+DGSEM blending factor. 

Replaces the Persson-\/\+Peraire modal indicator inside Hybrid\+DGSEM. The network is {\itshape per element}\+: its input is the standardized density profile of a single element (P+1 values) and its output is a single alpha in \mbox{[}0,1\mbox{]} (Sigmoid). Because the policy is local it is independent of the number of elements and can be reused across mesh sizes for a fixed polynomial order P.
