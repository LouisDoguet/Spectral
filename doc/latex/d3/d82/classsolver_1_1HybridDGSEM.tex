\doxysubsection{Detailed Description}
Entropy-\/stable hybrid DGSEM solver (Hennemann et al., JCP 2021). 

Each time step\+:
\begin{DoxyEnumerate}
\item Compute per-\/element blending factor alpha\mbox{[}e\mbox{]} from the Persson-\/\+Peraire modal energy indicator applied to density (Eqs. 40-\/48 of the paper).
\item Advance U\texorpdfstring{$^\wedge$}{\string^}n -\/\texorpdfstring{$>$}{>} U\texorpdfstring{$^\wedge$}{\string^}\{n+1\} with classical \doxylink{classsolver_1_1RK4}{RK4}, using Mesh\+::compute\+Hybrid\+Residual(alpha) instead of compute\+Residual().
\end{DoxyEnumerate}

The blending factor controls the amount of first-\/order FV dissipation\+: alpha = 0 -\/\texorpdfstring{$>$}{>} pure high-\/order entropy-\/conservative DGSEM. alpha = 1 -\/\texorpdfstring{$>$}{>} pure first-\/order entropy-\/stable FV.

Parameters (set via set\+Indicator\+Params)\+: alpha\+\_\+max \+: cap on alpha (default 0.\+5, recommended for N=4). alpha\+\_\+min \+: values below this are clipped to 0 (default 0.\+001). diffuse \+: whether to spread alpha to neighbours (default true).
