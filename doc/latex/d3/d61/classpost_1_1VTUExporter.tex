\doxysubsection{Detailed Description}
Writes VTU/\+PVD output files for a spectral-\/element mesh. 

Default fields (rho, velocity, pressure, a\+\_\+viscosity) are registered automatically. {\ttfamily lap\+\_\+pressure} and any sensor outputs (e.\+g. {\ttfamily div\+\_\+laplacian}) are opt-\/in\+: register them with add\+Field(\+VTUExporter\+::field\+Lap\+Pressure()) or add\+Sensor\+Field(name, sensor) before calling run().
