Detailed Description

Writes VTU/PVD output files for a spectral-element mesh.

Default fields (rho, velocity, pressure, a_viscosity) are registered automatically. lap_pressure and any sensor outputs (e.g. div_laplacian) are opt-in: register them with addField(VTUExporter::fieldLapPressure()) or addSensorField(name, sensor) before calling run().

◆ useComputedNodes()

void post::VTUExporter::useComputedNodes ( bool  enable)
inline

Export at the genuine computed nodes instead of a uniform grid.

When enabled, each element is sampled at its own basis quadrature nodes (GLL nodes for Lagrange) at their true physical positions, and field values are the raw nodal solution (interpolation at the nodes is exact). This shows the actual computed data, not a uniform re-projection. In this mode the per-element point count is fixed to P+1 (n_plot is ignored).
