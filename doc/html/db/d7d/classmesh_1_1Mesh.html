void mesh::Mesh::adaptBasis ( sens::PerssonPeraire & sensor,
int truncation,
double s_shock,
double s_smooth )

Per-element basis switching driven by the Persson-Peraire shock indicator log10(Se):

  • currently on primary, logSe > s_shock -> migrate to alt
  • currently on alt, logSe < s_smooth -> migrate back to primary Each migration triggers Element::setBasis (re-interpolation + setFlux). Caller is responsible for calling this between time steps only.
