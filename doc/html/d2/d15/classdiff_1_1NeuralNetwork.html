Detailed Description

Diffusion driven by a trained neural network.

The network predicts optimal alpha values for the hybrid DGSEM solver. Takes nodal density/energy values and outputs alpha [0,1] for blending between high-order and low-order (FV) flux computations.

For hybrid DGSEM: R = alpha * R_FV + (1-alpha) * R_DG

Input: Concatenated nodal values [rho_elem0, ..., rho_elemN] Output: Per-element alpha values [alpha_elem0, ..., alpha_elemN]
